Question 1: Finding Transfer Functions Using Newton's Second Law of Motion

Step 1: Applying Newton's Second Law of Motion to derive equations of motion

For Mass M₁ (1 kg):

According to Newton's Second Law: F = ma

M₁ · ẍ₁ = -K₂x₁ - K₃(x₁-x₂) - fv₂ · ẋ₁

1 · ẍ₁ = -1 · x₁ - 1 · (x₁-x₂) - 1 · ẋ₁

ẍ₁ = -2x₁ + x₂ - ẋ₁

For Mass M₂ (1 kg):

M₂ · ẍ₂ = K₃(x₁-x₂) - fv₃ · ẋ₂ + F(t)

1 · ẍ₂ = 1 · (x₁-x₂) - 1 · ẋ₂ + F(t)

ẍ₂ = x₁ - x₂ - ẋ₂ + F(t)

For Mass M₃ (1 kg):

M₃ · ẍ₃ = -K₁x₃ - fv₁ · ẋ₃ + K₁x₁

1 · ẍ₃ = -1 · x₃ - 1 · ẋ₃ + 1 · x₁

ẍ₃ = -x₃ - ẋ₃ + x₁

Step 2: Applying Laplace Transform to convert time-domain to frequency-domain

For M₁:

ℒ{ẍ₁} = ℒ{-2x₁ + x₂ - ẋ₁}

s²X₁(s) = -2X₁(s) + X₂(s) - sX₁(s)

s²X₁(s) + sX₁(s) + 2X₁(s) = X₂(s)

X₁(s)(s² + s + 2) = X₂(s)

X₁(s) = X₂(s)/(s² + s + 2)

For M₂:

ℒ{ẍ₂} = ℒ{x₁ - x₂ - ẋ₂ + F(t)}

s²X₂(s) = X₁(s) - X₂(s) - sX₂(s) + F(s)

s²X₂(s) + sX₂(s) + X₂(s) = X₁(s) + F(s)

X₂(s)(s² + s + 1) = X₁(s) + F(s)

For M₃:

ℒ{ẍ₃} = ℒ{-x₃ - ẋ₃ + x₁}

s²X₃(s) = -X₃(s) - sX₃(s) + X₁(s)

s²X₃(s) + sX₃(s) + X₃(s) = X₁(s)

X₃(s)(s² + s + 1) = X₁(s)

X₃(s) = X₁(s)/(s² + s + 1)

Step 3: Solving algebraically for transfer functions

Substitute X₁(s) = X₂(s)/(s² + s + 2) into equation for M₂:

X₂(s)(s² + s + 1) = X₂(s)/(s² + s + 2) + F(s)

Multiply both sides by (s² + s + 2):

X₂(s)(s² + s + 1)(s² + s + 2) = X₂(s) + F(s)(s² + s + 2)

X₂(s)[(s² + s + 1)(s² + s + 2) - 1] = F(s)(s² + s + 2)

Expanding (s² + s + 1)(s² + s + 2):

= (s²)(s²) + (s²)(s) + (s²)(2) + (s)(s²) + (s)(s) + (s)(2) + (1)(s²) + (1)(s) + (1)(2)

= s⁴ + s³ + 2s² + s³ + s² + 2s + s² + s + 2

= s⁴ + 2s³ + 4s² + 3s + 2

Therefore:

X₂(s)[s⁴ + 2s³ + 4s² + 3s + 2 - 1] = F(s)(s² + s + 2)

X₂(s)[s⁴ + 2s³ + 4s² + 3s + 1] = F(s)(s² + s + 2)

Final Transfer Functions:

X₂(s)/F(s) = (s² + s + 2)/(s⁴ + 2s³ + 4s² + 3s + 1)

X₁(s)/F(s) = X₁(s)/X₂(s) · X₂(s)/F(s) = 1/(s² + s + 2) · (s² + s + 2)/(s⁴ + 2s³ + 4s² + 3s + 1) = 1/(s⁴ + 2s³ + 4s² + 3s + 1)

X₃(s)/F(s) = X₃(s)/X₁(s) · X₁(s)/F(s) = 1/(s² + s + 1) · 1/(s⁴ + 2s³ + 4s² + 3s + 1) = 1/[(s² + s + 1)(s⁴ + 2s³ + 4s² + 3s + 1)]

Question 3: Determining Impulse Response Using Inverse Laplace Transform

For the transfer function X₁(s)/F(s) = 1/(s⁴ + 2s³ + 4s² + 3s + 1)

Step 1: Find roots of the characteristic equation

s⁴ + 2s³ + 4s² + 3s + 1 = 0

Let's denote the roots as -α₁, -α₂, -α₃, and -α₄ (these would need to be found numerically for exact values).

Step 2: Express using partial fraction expansion

1/(s⁴ + 2s³ + 4s² + 3s + 1) = A₁/(s+α₁) + A₂/(s+α₂) + A₃/(s+α₃) + A₄/(s+α₄)

The coefficients A₁, A₂, A₃, A₄ are found using the residue method:

A₁ = [(s+α₁) × (1/(s⁴ + 2s³ + 4s² + 3s + 1))]|s=-α₁

Similarly for A₂, A₃, and A₄.

Step 3: Apply inverse Laplace transform

h₁(t) = ℒ⁻¹{1/(s⁴ + 2s³ + 4s² + 3s + 1)}

h₁(t) = A₁e⁻α₁ᵗ + A₂e⁻α₂ᵗ + A₃e⁻α₃ᵗ + A₄e⁻α₄ᵗ, for t ≥ 0

For the transfer function X₂(s)/F(s) = (s² + s + 2)/(s⁴ + 2s³ + 4s² + 3s + 1)

Step 1: Express using partial fraction expansion

(s² + s + 2)/(s⁴ + 2s³ + 4s² + 3s + 1) = B₁/(s+α₁) + B₂/(s+α₂) + B₃/(s+α₃) + B₄/(s+α₄)

The coefficients B₁, B₂, B₃, B₄ are found using the residue method.

Step 2: Apply inverse Laplace transform

h₂(t) = ℒ⁻¹{(s² + s + 2)/(s⁴ + 2s³ + 4s² + 3s + 1)}

h₂(t) = B₁e⁻α₁ᵗ + B₂e⁻α₂ᵗ + B₃e⁻α₃ᵗ + B₄e⁻α₄ᵗ, for t ≥ 0

For the transfer function X₃(s)/F(s) = 1/[(s² + s + 1)(s⁴ + 2s³ + 4s² + 3s + 1)]

Step 1: Find roots of the additional quadratic term

s² + s + 1 = 0

Using the quadratic formula: s = (-1 ± √(1-4))/2 = (-1 ± √(-3))/2 = -0.5 ± j0.866

The roots are complex conjugates: -β₁ = -0.5 + j0.866 and -β₂ = -0.5 - j0.866

Step 2: Express using partial fraction expansion

1/[(s² + s + 1)(s⁴ + 2s³ + 4s² + 3s + 1)] = C₁/(s+β₁) + C₂/(s+β₂) + C₃/(s+α₁) + C₄/(s+α₂) + C₅/(s+α₃) + C₆/(s+α₄)

The coefficients C₁, C₂, C₃, C₄, C₅, C₆ are found using the residue method.

Step 3: Apply inverse Laplace transform

h₃(t) = ℒ⁻¹{1/[(s² + s + 1)(s⁴ + 2s³ + 4s² + 3s + 1)]}

h₃(t) = C₁e⁻β₁ᵗ + C₂e⁻β₂ᵗ + C₃e⁻α₁ᵗ + C₄e⁻α₂ᵗ + C₅e⁻α₃ᵗ + C₆e⁻α₄ᵗ, for t ≥ 0

Since β₁ and β₂ are complex conjugates, we can rewrite the first two terms as:

C₁e⁻β₁ᵗ + C₂e⁻β₂ᵗ = e⁻⁰·⁵ᵗ(D₁cos(0.866t) + D₂sin(0.866t))

Therefore:

h₃(t) = e⁻⁰·⁵ᵗ(D₁cos(0.866t) + D₂sin(0.866t)) + C₃e⁻α₁ᵗ + C₄e⁻α₂ᵗ + C₅e⁻α₃ᵗ + C₆e⁻α₄ᵗ, for t ≥ 0
